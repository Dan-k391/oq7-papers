Checking the frozen formalization

Requirements: Git (for the bundle route), Python 3, the pinned Lean toolchain with Lake, and the pinned dependency sources/build artifacts. Fetching the toolchain or dependencies may require network access. Preserve the supplied ZIP and bundle; configure and check a disposable extraction or clone.

  1. Verify the two SHA-256 digests against S2 and the copy manifest. For example, from the publication directory in PowerShell: 
    Get-FileHash -Algorithm SHA256 reproducibility/OQ7-complete-physical-theorem11-source.zip
Get-FileHash -Algorithm SHA256 reproducibility/OQ7-complete-physical-theorem11.bundle
  2. From the publication directory, create a new clone and select the exact commit: 
    git clone reproducibility/OQ7-complete-physical-theorem11.bundle oq7-replay
cd oq7-replay
git checkout --detach 686402a6c2d63820828729cc7ab02504632e3fe7
    Alternatively, extract the source ZIP into a new directory. The ZIP's paths are relative to its root; inspect README.md, lean-toolchain, and sources/pinned-lake-manifest.json there.
  3. In that disposable directory, configure portable package paths without upgrading dependency revisions or changing Lean sources: 
    python configure.py
lake resolve-deps
lake build OQ7 PrescribedExtinction
lake env leanchecker --fresh --verbose PrescribedExtinction
    configure.py rewrites only the build configuration and restores the pinned manifest. Its optional --packages-directory argument accepts an existing clean cache at the exact recorded revisions. For a dependency-from-source audit, separately verify dependency source revisions and rebuild dependency artifacts in the disposable environment; cache reuse is a different procedure.
  4. On Windows, the archived scripts also reproduce the documented checks when the pinned Lean bin directory is supplied: 
    ./verify.ps1 -LeanBin 'C:/path/to/lean-4.34.1-windows/bin' -Clean -BuildThreads 2
./verify-milestones.ps1 -LeanBin 'C:/path/to/lean-4.34.1-windows/bin' -Only obligation-1-universal-passivity,outgoing-weak-uniqueness,obligation-3-full-physical-optics,obligation-4-universal-nonattainment,obligation-5-complete-physical-theorem
./verify-kernel.ps1 -LeanBin 'C:/path/to/lean-4.34.1-windows/bin'
    These scripts write evidence in the disposable checkout. The project verifier's -Clean option cleans the project; it does not certify a full rebuild of shared dependency caches.
  5. For exact publication declaration exports, run lake env lean on the accompanying PublicationCheck.lean and CorrespondenceCheck.lean, using their absolute paths from the configured disposable checkout. Compare the output with S1 and S3. Recheck the 378 certified library-file hashes against verification/clean-build-source-hashes.json; the build-configuration changes are distinct from Lean-source identity.
