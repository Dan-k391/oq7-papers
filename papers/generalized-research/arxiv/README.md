# Channel and thickness arXiv revision

**Reciprocal Absorption Asymmetry: Sharp Channel Tradeoffs and Dielectric Thickness Asymptotics**

Daniel Wang, McMaster University, `denialk391@gmail.com`; Junjie Zheng, Columbia University, `zjj2785@gmail.com`, in that order.

The [16-page PDF](paper.pdf) is generated from [reconstructed TeX](main.tex) and [references.bib](references.bib). Upload [arxiv-source.zip](arxiv-source.zip), which contains compilation inputs only. [REVISION_NOTES.md](REVISION_NOTES.md) records the original-to-revised section mapping, scope corrections, bibliography changes and validation.

Build from the repository root with `python scripts/build-arxiv.py generalized-research`; use `--tex-dir` for a non-PATH TeX Live installation. The build disables shell escape and writes scratch files under `.local/`. See the collection's [submission instructions](../../../ARXIV_SUBMISSION.md).
