# Quartic Maxwell arXiv revision

**Uniform Quartic Bounds for Reciprocal Absorption–Scattering Asymmetry**

Daniel Wang, McMaster University, `denialk391@gmail.com`; Junjie Zheng, Columbia University, `zjj2785@gmail.com`, in that order.

The [13-page PDF](paper.pdf) is generated from [reconstructed TeX](main.tex) and [references.bib](references.bib). Upload [arxiv-source.zip](arxiv-source.zip), which contains compilation inputs only. [REVISION_NOTES.md](REVISION_NOTES.md) records the complete claim disposition and original PDF hashes.

Build from the repository root with `python scripts/build-arxiv.py quartic-maxwell`; use `--tex-dir` for a non-PATH TeX Live installation. The build disables shell escape and writes scratch files under `.local/`. See the collection's [submission instructions](../../../ARXIV_SUBMISSION.md).
